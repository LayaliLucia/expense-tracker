# 💰 Expense Tracker – Python Project

This project was developed as part of my **Python programming coursework**.  
It focuses on building a simple **expense tracking application** where users can record, manage, and analyze their spending.  
Unlike database-driven systems, this version uses **Python data structures** (lists, dictionaries, or files) to store and process expenses.

## ✨ Project Overview
The system allows:
- Adding expenses with details (amount, category, date)
- Categorizing expenses (e.g., food, transport, bills, entertainment)
- Viewing summaries of spending patterns
- Generating simple reports using Python logic

## 🛠️ Technologies Used
- **Python** for application logic
- **File handling (CSV)** for saving and loading data
- **Tkinter** for user interface (depending on implementation)

## 🎯 Purpose
The goal of this project was to:
- Apply Python programming skills to a real-world scenario
- Practice working with data structures and file handling
- Demonstrate how Python can support personal finance tracking
- Present the project as part of my coursework
